# M2 Test Report — Register Access, ARC Firmware Messaging, Heartbeat

**Date:** 2026-07-07 · **Status: ACCEPTED**

## Environment

- Guest: Windows 11 (26200) under local QEMU 8.2.2/KVM with `ttsim-bh` backed by
  the **heartbeat-patched** libttsim (`test/qemu-ttsim/build-ttsim.sh`: pristine
  copy of ../ttsim + `apply-heartbeat-patch.py`, which adds telemetry tag 32
  advancing with the simulation clock — stock ttsim's table is static and lacks
  tag 32; the patch preserves the only semantic tt-kmd relies on).
- Driver Verifier 0x9BB active on ttkmd.sys for the entire run
  (`verifier /query`: `MODULE: ttkmd.sys (load: 2)`).
- Build: /W4+WX + Code Analysis (DriverRecommendedRules) clean, incl. the new
  `blackhole.c` MMIO/queue code.

## What was ported (all verified against source, analysis §07/§09/§10)

- Kernel TLB window 201 programming: 96-bit TLB_2M register composed by explicit
  bit placement (blackhole.c:112-137 layout; MSVC-safe), strict ordering,
  reprogrammed per 32-bit NOC access under `KernelTlbLock`
  (kernel_tlb_mutex parity, blackhole.c:243-268).
- CSM accessors with the `[0x10000000, +512K)` range gate (telemetry.h:75-78).
- `arc_msg_push`/`arc_msg_pop` (msgqueue.c): [0,2N) pointer arithmetic,
  unsigned wrap `% 2N` occupancy, all-ones device-gone early exits on every
  pointer read, 1000 ms timeouts, 100 µs polls, explicit `KeMemoryBarrier()`
  at entry→WPTR and WPTR→doorbell boundaries (analysis §09.6 porting note).
- `send_arc_message` (blackhole.c:500-540): 500 ms `ARC_BOOT_STATUS` ready gate
  with NOC-hang all-ones abort, QCB discovery via `RESET_SCRATCH(11)`,
  `ARC_MSI_FIFO` doorbell (write 0), success = response header 0.
- `telemetry_probe` (blackhole.c:455-498): scratch-pointer discovery, version
  gate (major ≤ 1), tag scan into the 128-slot cache; `read_telemetry_tag`
  errno parity (-EINVAL / -ENODATA / csm-range).
- Debug ioctl surface (READ_TELEMETRY, ARC_MSG) behind `TT_DEBUG_INTERFACES`.

## Acceptance evidence (ttinfo.exe in guest: 2 devices, 0 failures, exit 0)

- **Heartbeat advancing on ttsim**: tag 32 read twice, 1.5 s apart:
  `16645 -> 16662`. Full path exercised: ioctl → tag cache → CSM read → kernel
  TLB window → ttsim ARC tile.
- **ARC round-trip**: TEST (0x90) pushed, doorbell rung, response popped with
  header 0 — against ttsim's independent C++ implementation of the same queue
  protocol (`tile.cpp: arc_drain_queue`), which validates the ring arithmetic,
  entry layout, and doorbell path end to end.
- Telemetry value parity vs ttsim's CMFW table: board-ID-high 0x400 (P150),
  AICLK 1000; absent tag (5) → ERROR_NOT_FOUND; tag ≥ 128 →
  ERROR_INVALID_PARAMETER; soft device → ERROR_NOT_SUPPORTED.
- All M1 checks re-ran green (no regressions).
